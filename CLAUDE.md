# CLAUDE.md

## Tech Stack

- Monorepo: pnpm workspace (`apps/*`, `packages/*`)
- Frontend (`apps/web`): Next.js (App Router) 16.2.9, React 19.2.4, Panda CSS
- Backend (`apps/api`): NestJS 11 (port 4000, global prefix `/api`)
- TypeScript: 5.9.3
- ESLint: 9.39.4 (+ Steiger for FSD boundaries in `apps/web`)
- Prettier: 3.8.4

## Repository Layout

- `apps/` — deployable applications (frontend AND backend)
- `packages/` — shared libraries (create when first needed)
- Root scripts: `pnpm dev` (web+api parallel), `dev:web`, `dev:api`, `build`, `lint`, `format`

## Frontend Structure (apps/web) — FSD

- `app/` (repo: `apps/web/app/`) is Next.js routing ONLY — keep route files thin,
  delegate rendering to `src/_pages/<slice>`
- `src/` contains FSD layers only:
  - `_pages/` — page compositions (prefixed with `_` to avoid Next.js `pages/` conflict;
    official FSD convention for Next.js)
  - `shared/` — cross-cutting code (api client, config, ui)
  - `widgets/`, `features/`, `entities/` — create only when the first use case arrives;
    do NOT scaffold empty layers
- Import rules (enforced by Steiger, `pnpm --filter @repo/web lint`):
  - A layer may import only from layers BELOW it (`_pages` → `widgets` → `features` →
    `entities` → `shared`)
  - Slices are imported through their public API (`index.ts`) only — never deep-import
    another slice's internals

## Styling (apps/web) — Panda CSS

- Single styling system: Panda CSS (`css()`, recipes). Do not add CSS Modules or other
  styling libraries
- `styled-system/` is codegen output (gitignored, regenerated by the `prepare` script) —
  never edit or commit it
- Global styles live in `panda.config.ts` (`globalCss`); `app/globals.css` holds only the
  Panda layer declaration
- Design tokens: use Panda theme tokens once design is finalized; page-local palettes may
  use CSS variables until then

## Coding Conventions

- Naming
  - camelCase for functions and variables
  - PascalCase for components, types, and component/class file names
  - kebab-case for non-component file names and directory names
  - UPPER_SNAKE_CASE for exported constants
- Indentation: 2 spaces
- Do not use `React.FC`
- Prefer `type` over `interface`
- `export default` is allowed only for page components
- Import order: external packages → internal alias (`@/*`) → relative paths
- `any` type is forbidden
- Minimize direct DOM access (`document`, `window`)
- Minimize `'use client'`; use it only when strictly necessary
- Extract any string reused 2+ times into a constant
- Console usage
  - Allowed: `console.info`, `console.warn`, `console.error`, `console.table`
  - Not allowed: `console.log`, `console.debug`, `console.dir`, `console.time`
- All code comments must be written in Korean
