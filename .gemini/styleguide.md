# 코드리뷰 스타일 가이드

## 리뷰 언어
- 모든 리뷰 코멘트는 **한국어**로 작성한다.

## 프로젝트 컨텍스트
- 법인전환 의사결정 플랫폼. 모노레포(Next.js 클라이언트 + Nest.js 서버, pnpm workspace)로 전환 중.
- 클라이언트는 FSD(Feature-Sliced Design) 아키텍처, 스타일링은 PandaCSS를 사용한다.

## 중점 리뷰 항목
- **세금 계산 로직**: 순수 함수로 작성되어야 하고, 세율·보험료율 같은 상수는
  하드코딩하지 않고 설정 객체로 외부화한다. 계산식 변경은 테스트 코드 동반 여부를 확인한다.
- **비즈니스 로직 테스트**: 서버 코드와 계산 로직에는 테스트가 있어야 한다.
  UI 전용 코드는 테스트를 강제하지 않는다.
- **FSD 레이어 위반**: 하위 레이어가 상위 레이어를 import하지 않는지 확인한다.
- **금액 표기**: 금융 숫자는 한국식 콤마 표기(`1,000원`)와 tabular-nums를 따른다.

## 지양할 코멘트
- 스타일·포맷 지적 (Prettier/ESLint가 처리)
- 사소한 네이밍 취향 차이
- 근거 없는 추측성 지적
